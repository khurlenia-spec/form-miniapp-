# FORM — Telegram Mini App

Персональная система питания, тренировок и прогресса. Разработка Александра Гурлени.

## Что внутри

- `public/index.html` — собранное мини-приложение (не править вручную).
- `src/` — исходники: `data.js` (продукты, рецепты), `logic.js` (расчёты), `avatar.js` (герой), `app.js` (экраны), `style.css`. Сборка: `python3 build.py`.
- `server.ts` — сервер на Bun: отдаёт приложение, хранит прогресс клиентов в Postgres (с проверкой подписи Telegram), принимает вебхук бота, пересылает сообщения тренеру.
- `reminders.ts` — напоминания: утром «план готов», вечером — чек-ин. Запускается по расписанию.

## Переменные окружения

| Переменная | Где | Что это |
|---|---|---|
| `BOT_TOKEN` | web, reminders | токен бота из @BotFather (секрет) |
| `DATABASE_URL` | web, reminders | строка подключения к Postgres |
| `COACH_CODE` | web | код, которым тренер подтверждает себя: `/coach КОД` |
| `APP_URL` | reminders | публичный адрес приложения, например `https://form.up.railway.app/` |

Вебхук, кнопка меню и команды бота настраиваются автоматически при старте сервера.

## Команды бота

- `/start` — приветствие и кнопка «Открыть FORM»
- `/coach КОД` — назначить этот аккаунт тренером
- `/clients` — сводка по клиентам (только тренер)
- `/notify_off`, `/notify_on` — напоминания

Тренер отвечает клиенту, ответив (reply) на его сообщение в чате с ботом.
